# Kooki Bakes

A responsive website for a student-owned cookie bakery in Las Piñas.
Visitors can learn about the bakery, browse sample cookies, and
contact the business through Facebook.

## Features

- Responsive navigation and layout
- About section
- Cookie menu cards
- Facebook contact link

## Technologies Used

- HTML
- CSS
- Bootstrap

## File Structure

Kooki_Bakes/
├── index.html
├── css/
│   └── style.css
├── images/
│   └── classic.webp
└── README.md

## How to Run

1. Download or extract the project folder.
2. Open the folder in Visual Studio or Visual Studio Code.
3. Open index.html in a web browser.

An internet connection is required to load Bootstrap from its CDN.

## Template and Components

The website uses Bootstrap's starter structure, responsive grid,
navigation, buttons, and card components. Custom CSS adapts the
colors and appearance to the Kooki Bakes design.

Source: https://getbootstrap.com/docs/5.3/getting-started/introduction/
